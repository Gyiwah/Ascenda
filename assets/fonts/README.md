# Font Setup

## Dustrone Font

To use the Dustrone font for the "Ascenda" title on the login screen:

1. Download the Dustrone font file (Dustrone-Regular.ttf)
2. Place it in this directory: `assets/fonts/Dustrone-Regular.ttf`
3. The app will automatically load and use it

If the font file is not found, the app will gracefully fall back to the system default font.

**Note:** The font is only applied to the "Ascenda" title on the login screen. All other text uses the system font.
